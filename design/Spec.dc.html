House rules for the redesign

the four rules the mockups obey — so a new number has one obvious place to go
1

Unit discipline

a bare number is banned — every value carries the suffix that says what it is

2

Colour carries one meaning each

no decorative colour anywhere
greenthe plan taken · a gate passed also the only colour a positive Δ may use
amberblocked · a threshold missed · distrust never means "bad", means "you set a rule and it bit"
redmoney leaving: tax, broker, a negative Δ reserved for outflow, never for warnings
cyanmeasured this run · the sells branch the fetched, verifiable half of any figure
violetyour setting, not the market's so a number you can change is visibly yours
slatethe give-up branch · modelled, not observed deliberately dull: it is the half you did not earn yet
3

Three tiers, and hover is not one of them

nothing that decides a verdict may live behind a pointer
tier 1 · the row
always on screen
  • verdict badge
  • all candidates: price, net, odds
  • the gate line: floor → passed → ranked → margin
  • book, outcome, market, rank
tier 2 · expanded
one click, scrolls
  • measured inputs with sources
  • your settings
  • candidate ledger, full width
  • branch bars and the evaluated formula
  • the gate, step by step
  • the chart
tier 3 · hover
exact values only
  • the unrounded figure behind a short one: 4.62M → 4,618,095.25
  • a full item name that was truncated
  • nothing else. Ever.
